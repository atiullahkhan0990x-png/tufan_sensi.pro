# 🎯 ZX TUFAN PRO SENSI V8.0

**Ultimate Free Fire Esports Hub for ZX TUFAN Squad**

A fully client-side web application that generates device-specific Free Fire sensitivity settings, analyzes HUD screenshots, creates stylish nicknames, and scans real Android hardware via Termux.

## ✨ Features
- **✨ Generate Sensitivity**: 59 phone models with RAM, refresh rate, and DPI calculation tuned for recoil control and headshot accuracy.
- **📸 HUD Geometry Analyzer**: Upload a HUD screenshot. It reads the aspect ratio and calculates fire button size & drag zone.
- **📱 Termux Hardware Scanner**: Get exact hardware-based sensitivity via `main.py` and `device_report.json`.
- **🔥 Nickname Generator**: Stylish esports nicknames with one-tap copy.
- **💾 Sensi Vault**: Save generated profiles locally in your browser.

## 🚀 How to Use
1. Extract the ZIP archive and place your squad/preset images (`zxtufan.jpg`, `ritesh.jpg`, `faisal.jpg`, `squad.jpg`, `zxtufansensi.jpg`) in the same folder.
2. Open `index.html` in any modern browser or upload all files to GitHub Pages.
3. Use the tabs to navigate features.
4. For the Termux scanner, download `main.py` from the **TERMUX SCAN** tab, run it in Termux, and upload `device_report.json`.

## ⚠️ Disclaimer
This tool does not modify game files or provide unfair advantages. It only calculates sensitivity recommendations based on hardware specs.
