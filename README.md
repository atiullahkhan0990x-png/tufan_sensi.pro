# 🌪️ TUFAN SENSI - Premium Free Fire Tools

Ye ek premium website hai jo Free Fire players ke liye banayi gayi hai.

## 🚀 Features
1. **TUFAN SENSI:** Device (RAM, FPS, DPI, Age) ke hisaab se real sensitivity generate karta hai.
2. **Freestyle Name:** Free Fire ke liye premium stylish names banata hai with symbols.
3. **Pro Dashboard:** ZX TUFAN, RITESH BOSS, FAISAL BOSS, aur SQUAD ki premium profile images.

## 🛠️ Kaise Chalayein?
1. Saari files ko ek folder mein rakhein (index.html, style.css, script.js).
2. `index.html` file ko kisi bhi browser (Chrome, Safari) mein open karein.
3. Website ready hai!

## 🖼️ Images Kaise Badlein?
`index.html` file mein jayein. Wahan `<img src="...">` tags milenge. Wahan `src=""` ke andar apni images ka link daal dein.
